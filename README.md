# Online Tour Planner

A web-based tour planning and booking application built with Java and Spring Boot.

## Features

- User registration and login
- Tour/package browsing
- Trip and booking management
- User dashboard
- Admin dashboard
- Booking confirmation
- Email service integration
- H2 database integration

## Tech Stack

- Java 17
- Spring Boot
- Spring Data JPA
- Thymeleaf
- Spring Web MVC
- H2 Database
- Maven
- Lombok

## Project Structure

- `controller` – Handles web requests
- `model` – Defines application entities
- `repository` – Handles database operations
- `service` – Contains application services
- `templates` – Thymeleaf HTML templates

## How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Ensure Java 17 is configured.
4. Run `OnlinetourplannerApplication`.
5. Open the application in your browser.
